## 한글 요약

거대 비전-언어 모델 경쟁이 놓치는 현실 — 대부분의 운영 환경엔 무한한 컴퓨트가 없다 — 에서 출발해, 구글 Gemma 4 계열의 경량 모델 E2B 를 Unsloth 로 파인튜닝해 좁은 시각 과제에서 얼마나 정확도를 끌어올릴 수 있는지 실험한 기록이다. 하드웨어는 Kaggle 무료 T4 x2(VRAM 16GB), 과제는 차트 이미지를 읽고 질문에 답하는 ChartQA 벤치마크다. ChartQA 는 축 레이블·범례·플롯 포인트를 읽는 지각과 논리 추론을 동시에 요구하고, 사람이 쓴 질문과 기계 생성 템플릿 질문이 나뉘어 있어 엄격한 스키마 출력과 자연어 모호성 처리를 각각 평가할 수 있다. 전체 노트북은 Kaggle 에 공개돼 있다.

**왜 소형 모델인가.** 좁은 도메인 과제에 범용 대형 모델은 과하다. 기반 VLM 은 이미 저수준 시각 개념과 언어 구조를 알고 있으므로, 목표는 "보는 법"을 처음부터 가르치는 게 아니라 기존 시각 표현을 특정 출력 형식으로 **조향**하는 것이다. 문제를 기반 학습이 아닌 표적 파인튜닝으로 규정하면 하드웨어 요구가 급감한다. 메모리 관리의 핵심은 4비트 로딩(QLoRA)과 Unsloth 의 최적화된 gradient checkpointing 이며, 이 둘로 시퀀스 길이와 배치 메모리 여유를 확보한다.

**무엇을 가르치나.** 전통 이미지 분류의 "이미지 → 클래스"와 달리 VLM 파인튜닝은 "이미지 + 지시 → 목표 응답"의 조건부 텍스트 생성이다. 따라서 데이터를 OpenAI 스타일 멀티턴 대화 형식(user 턴 = 이미지 + 프롬프트, assistant 턴 = 정답)으로 변환한다. 저자는 이 "데이터 배관" 단계가 사실상 과제를 정의하는 곳이며, 프롬프트가 단순 래퍼가 아니라 모델의 시각 추론에 능동적으로 관여하는 요소가 된다고 강조한다.

**제로샷 베이스라인을 먼저.** 훈련 전 원본 모델을 대표 샘플로 평가하지 않으면 진짜 적응량을 측정할 수 없다 — 파인튜닝 후 정답이 나와도 원래 할 수 있었거나 포맷만 맞추면 되는 경우일 수 있다. 베이스라인은 데이터 파이프라인이 끝까지 동작하는지 확인하는 역할도 겸한다.

**PEFT 설정.** LoRA 로 어텐션·MLP 계층에 저랭크 학습 행렬을 주입하되, Unsloth 의 옵션으로 비전 인코더와 언어 디코더 **양쪽**을 동시에 대상으로 삼는다(r=32, alpha=32, all-linear). 시각 특징 추출과 텍스트 매핑을 함께 배우면서도 사전학습 지식은 보존한다. 훈련은 TRL 의 SFTTrainer 에 비전 전용 collator 를 붙이고, 8비트 AdamW·유효 배치 8(누적 4)·1 에폭·cosine 스케줄·max_length 1024 로 짧고 실용적으로 잡았다. 과적합이 아니라 어댑터가 얼마나 빨리 목표 스키마를 배우는지 확인하는 게 목적이다.

**평가.** 정성 비교 대신 Exact Match(토큰 단위 완전 일치)와 Relaxed Accuracy(공백·서식 차이 허용)를 200개 테스트 샘플에 대해 베이스라인과 파인튜닝 모델 양쪽에 돌렸다. 결과:

| 지표 | 베이스라인 | 파인튜닝 후 | 향상 |
|---|---|---|---|
| Exact Match | 0.475 | 0.65 | +0.175 |
| Relaxed Accuracy | 0.675 | 0.75 | +0.075 |

훈련 샘플 4,000개, 1 에폭만으로 얻은 수치다. 사람/기계 생성 레이블별로도 나눠 봤다(그래프로만 제시).

**다음에 해볼 것.** (1) 모듈 절제 실험 — 비전 인코더를 동결하고 언어 계층만 튜닝해도 충분한지 비교해 VRAM·속도 트레이드오프를 밝히기. (2) 데이터 스케일링 곡선 — 100/500/1,000/5,000 샘플에서 성능을 찍어 실제 배포에 필요한 주석 작업량을 추정하기. (3) 분포 외 테스트 — 조명·해상도·미지 레이아웃에서 한계와 실패 모드를 드러내기.

결론 공식은 "소형 기반 VLM + 도메인 지시 + LoRA → 엣지 배포용 모델"이다. 목표는 Gemma 4 를 더 나은 범용 모델로 만드는 게 아니라 기존 표현을 특정 과제로 조향하는 것이고, 실제 엔지니어링 제약에서는 그 특화가 중요한 전부라는 것이다.

**적용 각도(참고용 메모)**: product-labeling(상품 이미지 Vision 분석)에서 Claude Haiku 호출 비용이 부담될 때, 소형 VLM 을 우리 라벨 스키마로 LoRA 튜닝해 로컬/엣지로 내리는 시나리오의 참고 레시피. "제로샷 베이스라인 먼저 → 스케일링 곡선으로 주석 필요량 추정" 절차는 그대로 가져올 만함.
